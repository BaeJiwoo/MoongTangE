# portable-physics-sandbox

C++20 기반의 크로스플랫폼 3D 물리 시뮬레이션 프로젝트입니다.

## 목표

- Windows, Linux, macOS에서 빌드 가능한 CMake 모노레포
- `Common`: 외부 물리 엔진을 사용하지 않는 수학, 물리, 게임 상태 및 프로토콜
- `Server`: 싱글플레이와 멀티플레이가 공유하는 서버 코어 및 독립 실행 서버
- `Client`: raylib 3D 렌더링, WASD 입력, 로컬 및 TCP 전송
- 서버 권위 방식의 60Hz 물리 시뮬레이션과 20Hz 상태 전송

## 개발 상태

저장소 초기화 단계입니다. 게임 구현과 빌드 설정은 후속 이슈별 PR에서 추가합니다.

초기 README 이후 모든 개발 변경은 실제 GitHub 이슈 번호를 사용하는 작업 브랜치에서 진행합니다. 의존성이 있는 변경은 Stacked PR로 제출하며, PR은 사용자가 리뷰하고 직접 병합할 수 있도록 열린 상태로 유지합니다.

## 예정 기술 스택

| 영역 | 기술 |
| --- | --- |
| 언어 | C++20 |
| 빌드 | CMake |
| 네트워크 | Standalone Asio |
| 렌더링 | raylib |
| 테스트 | CTest |
| CI | GitHub Actions |

빌드 및 실행 명령, 외부 의존성 라이선스와 플랫폼별 검증 결과는 구현 PR에 맞춰 문서화합니다.
