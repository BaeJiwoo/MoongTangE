# 수집 경기 루프 — Issues #89, #91

한 방에서 `3초 준비 → 90초 수집 → 결과 → 다음 판`을 반복합니다. 싱글플레이와 TCP
멀티플레이는 같은 `GameRound` 규칙을 사용하며 서버 Tick만 시간·점수·결과를 결정합니다.

## 플레이와 승패

| 항목 | 규칙 |
| --- | --- |
| 준비 | 180 Tick(3초). 공·물체와 입력 이동은 정지합니다. |
| 제한 시간 | 실제 플레이 5,400 Tick(90초). 메뉴를 열거나 사망해도 시간은 계속 갑니다. |
| 점수 | 먹은 음식마다 100점. 크기는 점수에 영향을 주지 않습니다. |
| 중복 방지 | 각 플레이어별로 누적 섭취 횟수를 최대 4096회로 제한합니다. 먹은 음식은 제거되며 같은 음식에 중복 점수를 지급하지 않습니다. |
| 혼자 플레이 | 20개/2000점 달성 즉시 승리. 90초에 도달하면 실패합니다. |
| 여러 명 플레이 | 참가자가 2명 이상이 되면 그 판은 경쟁 경기입니다. 90초 후 최고점이 승리하며, 최고점 동점은 공동 승리입니다. 모두 0점이면 승자가 없습니다. |
| 충돌 사망 | 부피가 15% 이상 큰 캐릭터에게 먹히면 탈락하고 `FAIL` 화면에서 개인 재시작을 요청할 수 있습니다. 점수·획득 이력과 남은 시간은 유지합니다. |
| 경기 종료 | 월드 물리와 점수를 고정합니다. 최종 Tick에서 획득한 물체도 반영한 뒤 한 번만 결과를 결정합니다. 죽은 플레이어도 누적 점수로 승리할 수 있습니다. |
| 다음 판 | 결과를 최소 180 Tick(3초) 보여 준 뒤 첫 유효 요청으로 방 전체가 재시작합니다. 접속·플레이어 ID·방 ID·입력 시퀀스는 유지하고, 점수·사망·물체와 위치를 초기화합니다. |

게임 시간은 고정 시뮬레이션 Tick 기준입니다. 서버가 과부하로 따라잡기 상한에 도달하면
실제 벽시계 시간과 달라질 수 있습니다. 클라이언트에서 자체적으로 승패를 예측하지 않습니다.

## 조작과 화면

- 메뉴에서 Single Player 또는 Multiplayer로 입장합니다.
- WASD로 이동하고 키를 놓으면 빠르게 정지합니다. 준비 화면에서 수집 목표를 확인합니다.
- 왼쪽 위는 내 점수/목표, 오른쪽 위는 남은 시간과 점수 순서입니다.
- 오른쪽 아래 레이더는 자신을 중심으로 50m를 표시합니다. 금색은 음식, 초록색은 지뢰, 빨강은 다른
  생존 캐릭터, 파랑은 자신입니다. 바깥 물체는 가장자리 방향으로 표시합니다. W/A/S/D 표시는
  카메라 회전과 무관한 이동 축과 일치합니다.
- 사망 시 Enter/R은 같은 판에서 개인 재시작, 경기 결과에서 Enter/R은 방 전체의 다음 판입니다.
- 결과 화면의 ESC/MAIN MENU는 나만 방에서 나갑니다. 재시작 요청은 서버 확인까지 중복 클릭을 막습니다.
- 기존 서버·Tick 디버그 대신 플레이 목표를 기본 HUD에 표시하고 F3 충돌 디버그는 유지합니다.

## 입장·이탈·재시작 경계

- 중도 입장은 현재 방의 남은 시간으로 참여합니다. 다음 판부터 같은 시작 조건으로 플레이합니다.
  결과 표시 중 입장하면 해당 결과를 보고 다음 판에 참가하며 지난 결과는 바뀌지 않습니다.
- 이탈자의 점수는 방에서 제거되고 이탈은 포기 처리합니다. 경쟁 경기에서 한 명만 남아도
  제한 시간은 유지하며 점수가 있어야 승리합니다. 이미 확정된 다른 사람의 승패는 재계산하지 않습니다.
- 모든 사람이 떠나면 새 준비 상태로 초기화합니다. 기존 방 만료·예약 정원 정책은 유지합니다.
  재접속은 새 세션이므로 이전 점수나 플레이어 ID를 복구하지 않습니다.
- 결과가 나오기 전의 다음 판 요청은 무시합니다. `next_round_id`는 현재 결과의 경기 번호와
  같아야 합니다. 최소 결과 표시 중 도착한 유효 요청은 저장했다가 3초 후 실행할 수 있습니다.
- 재시작에서도 서버 Snapshot Tick과 참가자 입력 시퀀스의 최고값을 유지합니다. 이전 판의
  입력·사망 토큰·경기 번호가 새 판을 이동시키거나 재시작하지 못하게 합니다.
- 새 판 배치는 `방 seed + roundId - 1`을 사용합니다. 화면은 판이 바뀔 때 이전 위치와 보간하지 않습니다.

## 한 판의 플레이 밀도

음식 64개로 시작하고 0.5초마다 하나를 보충하여 최대 96개를 유지합니다.
평면 경기장은 64×64m이고, 48×48m 영역에 음식을 생성합니다. 음식을 먹으면 몸체 반지름이
증가하며 부착물이나 구름 관성을 사용하지 않습니다. 지뢰는 큰 캐릭터의 질량을 40% 줄이되
점수는 유지합니다. [성장·지뢰 규칙](COLLECTIBLE_SYSTEM.md)을 참고하세요.

## 검증과 후속 범위

`RoundTests`는 시간 경계, 중복 점수 한도, 기본 seed에서 실제 이동 입력으로 목표 달성,
동점 공동 승리, 0점 무승부(승자 없음), 중도 입장/이탈, 결과 대기와 오래된 재시작을 검증합니다.
`IntegrationTests`는 전체 판과 다음 판을 직접/Protobuf 경로로 비교하고 실제 Local/TCP의
충돌 사망·개인 재시작 검증을 유지합니다. `SurvivalGuiSmoke`는 준비/HUD/결과 화면과 키 입력,
결과 우선순위와 대기 버튼을 검사합니다. `PhysicsTests`는 매우 작은 제동 속도에서 마찰 계산이
유한하게 유지되는 회귀 검증을 포함합니다.

현재 결과는 게스트 방 세션 안의 일시적 결과입니다. 계정별 기록 저장, 영구 최고 점수,
결과 API 제출, 재화 보상은 구현하지 않았으며 [TODO](../TODO.md)의 후속 범위입니다.
